# nmr-peak-assign

粗产物的 ¹H NMR 里，哪些峰是产物的，哪些是没反应完的原料，哪些是溶剂和水，
**剩下哪些峰谁也解释不了**？

`peakassign` 读入你的目标结构和一张带积分的峰表，把每个峰分到五个类别里。
它不去猜副产物是什么结构，只做一件事：用排除法把“不属于你给的候选物”的峰
揪出来，并且大声告诉你。

```
$ python -m peakassign examples/ethyl_benzoate/targets.yaml examples/ethyl_benzoate/measured_peaks.csv
   8.05   2.01H  产物        苯甲酸乙酯 ArH（C7,C11）
   7.55   0.97H  产物        苯甲酸乙酯 ArH（C9）
   7.44   2.03H  产物        苯甲酸乙酯 ArH（C8,C10）
   7.26   0.21H  溶剂/杂质     CHCl3（CDCl3 残留峰）
   4.38   1.98H  产物        苯甲酸乙酯 CH2（C2）
   3.72   0.60H  原料        乙醇 CH2（C2）
   3.50   1.98H  未知 !!
   1.56   0.42H  溶剂/杂质     H2O（CDCl3 中的水峰）
   1.39   3.01H  产物        苯甲酸乙酯 CH3（C1）
   1.24   0.92H  原料        乙醇 CH3（C1）
乙醇: 约为产物的 30 mol%，原料残留较多
[!] 发现疑似未知副产物信号，建议重点排查：3.50 ppm（1.98H）
report: examples/ethyl_benzoate/report.md
```

完整报告见 [examples/ethyl_benzoate/report.md](examples/ethyl_benzoate/report.md)。

## 安装

这个工具放在 `nmr-novelty-check` 的子文件夹里，直接复用父项目的位移预测和
已经建好的索引，所以要先把父项目装好、索引建好：

```
cd nmr-novelty-check
pip install -e .
nmrcheck build              # 已经建过索引就跳过

cd nmr-peak-assign
pip install -e .            # 额外只需要 pyyaml
```

没有索引也能跑，但预测位移会退化成按原子类型给的固定值，报告开头会提醒。

## 输入

`targets.yaml`：你知道的全部信息。

```yaml
product:
  smiles: CCOC(=O)c1ccccc1
  name: 苯甲酸乙酯            # name 可省，也可以直接写 product: CCOC(=O)c1ccccc1
reactants:
  - smiles: OC(=O)c1ccccc1
    name: 苯甲酸
  - smiles: CCO
    name: 乙醇
solvent: CDCl3                 # CDCl3、DMSO-d6、CD3OD、D2O、acetone-d6、CD3CN、C6D6、CD2Cl2

# 以下都可选
extra_solvents: [乙酸乙酯, 正己烷]      # 后处理用过、可能残留的溶剂
extra_peaks:                           # 表里没有的已知杂质，自己给位移
  - {name: BHT, ppm: 5.01}
reference: {ppm: 4.38, protons: 2}     # 手动指定积分参考峰，一般不需要
```

`measured_peaks.csv`：从仪器平台导出的峰表。积分用原始的相对面积就行，不用
自己先归一化。

```csv
ppm,integral,multiplicity
8.05,2.03,d
7.55,0.98,t
...
```

`multiplicity` 一列可以没有。

## 报告怎么读

| 类别 | 含义 |
| --- | --- |
| 1. 产物特征峰 | 位移和积分都对得上产物的峰，附原子归属建议和置信度（高/中） |
| 2. 未反应完的原料 | 匹配到反应物的峰，给出它相对产物的摩尔比；超过 20 mol% 标“原料残留较多” |
| 3. 溶剂与已知杂质 | 氘代溶剂残留峰、水峰，以及你在 `extra_solvents` 里声明的溶剂 |
| 4. ⚠️ 未知副产物预警 | 前三类都解释不了、归一化后积分 ≥ 0.5H 的峰。报告最上方和这一节都会醒目提示 |
| 5. 冲突与重叠 | 一个峰下面压着两种物质，或者位移像产物但积分对不上 |

积分不到 0.5H 的未归属小峰（¹³C 卫星峰、痕量杂质之类）单独列一行，不触发预警。

## 积分是怎么用上的

只看化学位移，粗产物谱基本理不清：预测位移本身有 0.1–0.3 ppm 的误差，产物、
原料、同系物的峰常常挤在同一个窗口里。积分是另一条独立的证据，这个工具在
四个地方用到它。

**1. 自动归一化。** 不需要你挑一个参考峰。程序会找一个比例，使尽可能多的产物
信号同时满足“积分 = 氢数”，这个比例就是 1H 对应的面积。某个产物峰下面压了
杂质也不要紧，其余的峰会把比例定住。

**2. 氢数校验。** 一个峰要归给预测的 CH₃，积分就得是 3H 左右（允许 15% +
0.1H 的误差）。位移对上、积分只有 1.0H 的峰不会被归给产物，而是进第 5 类并
写明“位移符合、积分对不上”。反过来积分多出来，说明下面还压着别的东西，多出
的部分会单独报出来。

**3. 原料自己跟自己比。** 残留原料的浓度和产物不同，不能要求它的积分等于氢数。
程序为每个原料单独拟合一个摩尔比，要求它的几组峰按氢数成比例。例子里乙醇的
CH₂ 是 0.60H、CH₃ 是 0.92H，正好是 2 : 3，于是确认是乙醇，残留约 30 mol%。
旁边 3.50 ppm 那个 2.0H 的峰虽然也在乙醇 CH₂ 的预测窗口内，但比例完全不对，
所以不会被当成乙醇吞掉。

**4. 一个原料至少要出现多数信号。** 只有一个峰碰巧落在某原料的窗口里、它其余
的信号都不见踪影，这个峰不会算作原料，而是留在未知里并注明原因。

每个预测信号最多用一次，产物优先；整个分配是全局搜索出来的，不是谁近归谁。

## 排除法

工具不推断副产物结构。它的逻辑是：

1. 产物先拿走能解释的面积；
2. 溶剂残留峰和水峰拿走一部分；
3. 每个原料拿走自洽的那部分；
4. 剩下的面积，谁也没认领，就是你要重点看的。

对未知峰，报告只给一条不带结论的线索：如果它的位移刚好和某个常见实验室溶剂
重合（比如 CDCl₃ 里甲醇在 3.49 ppm），会提一句，让你自己判断要不要把那个溶剂
加进 `extra_solvents` 重跑。多组峰的溶剂（乙酸乙酯、乙醚等）要所有峰都在、
积分成比例才算数。

### 关于重叠

产物峰同时落在某个原料的预测窗口内是常事（苯甲酸乙酯和苯甲酸的芳香氢就是）。
处理方式分三种：

- 那个原料已经通过别的峰确认存在：按比例它在这里应该贡献多少 H 是算得出来的，
  这个峰进第 5 类；
- 峰的积分比产物需要的多，而原料能解释多出的部分：进第 5 类，并给出拆分；
- 原料没检出，峰的积分也正好是产物的氢数：仍算产物峰，备注里写明它也在哪个
  原料的窗口内。想把这种情况也全部列进第 5 类，加 `--strict-overlap`。

## 参数

```
python -m peakassign targets.yaml measured_peaks.csv [-o report.md] [--json report.json]
```

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `--tol` | 0.08 | “高置信”的 ppm 偏差。搜索窗口 = tol + 预测的不确定度（见下） |
| `--unknown-threshold` | 0.5 | 触发未知预警的积分（H） |
| `--residual-alert` | 0.20 | 原料/产物摩尔比超过它就提示残留较多 |
| `--strict-overlap` | 关 | 见上 |
| `--data-dir` | `../data` | 父项目索引所在目录 |

搜索窗口为什么不是固定的 ±0.08：父项目的预测器是按原子环境查表的，环境越大
越准。它在留出集上的 ¹H 平均误差是 0.14 ppm（半径 4 根键）到 0.63 ppm
（半径 1）。所以窗口按半径放宽：半径 4 是 ±0.20，半径 3 是 ±0.28，以此类推。
窗口放宽以后，靠上面说的积分校验来防止乱归属。报告末尾的表里列了每个预测信号
实际用的窗口。

## 局限

- 预测位移是估算值，归属是建议。预测偏差超过窗口时，真实的产物峰会被报成未知，
  同时“没有找到的产物信号”里会多出一条，两边对照就能看出来。
- OH、NH 等活泼氢的位移随浓度和含水量漂移，只做宽松匹配，置信度最高给“中”。
- 不预测峰形。`multiplicity` 目前只用来判断水峰（必须是单峰或宽峰）和筛掉明显
  不符的溶剂线索。
- 只处理 ¹H。
- 常见溶剂杂质表（Fulmer et al., *Organometallics* 2010, 29, 2176）只录入了
  CDCl₃ 和 DMSO-d₆；其他氘代溶剂只内置残留峰和水峰，别的杂质用 `extra_peaks`
  自己给。
- 两个候选物的信号完全重合且积分也说得通时，程序分不开，只能标出来。

## 测试

```
pip install pytest

```

`tests/test_assign.py` 等用手写的预测值测试分配逻辑，不依赖 RDKit；
`tests/test_end_to_end.py` 用父项目的真实预测器和索引把苯甲酸乙酯的例子完整跑
一遍，没有索引时自动跳过。

例子里的峰表是合成的：苯甲酸乙酯的五组峰，0.3 当量的残留乙醇，CHCl₃ 残留峰，
水峰，再加一个与体系无关的 3.50 ppm / 2.0H 的峰。期望结果是前面那段输出。

## 和父项目的关系

复用（只读，不改动父文件夹里的任何东西）：

- `nmrcheck.predict.predict`：¹H 位移和每组氢数的预测；
- `nmrcheck.index.Index`：以只读方式打开 `data/index.sqlite` 查原子环境；
- `nmrcheck.chem.parse_smiles`：SMILES 解析；
- `nmrcheck.solvents`：氘代溶剂别名和残留峰位移。

本项目自己的部分是峰表和目标的读取、水峰与溶剂杂质表、带积分校验的分配算法
和报告。
